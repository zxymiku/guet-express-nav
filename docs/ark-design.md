# Ark 设计决策记录 — family: ark · depth: maximal（4/极繁）

> 依据 `.skills/ark-ui-skill-main/`（references/design-language.md、references/depth-levels.md）。
> 设计契约：`family = ark`（近黑 / 白 / 青色信号，直线导轨、方形控件、斜向切口）×
> `depth = maximal`（状态驱动仪表化、分节定制构图、全站动效协调、双端重艺术指导）。

## 1. 色彩令牌（src/styles/ark-tokens.css）

| 令牌 | 值 | 角色 |
| --- | --- | --- |
| `--ark-ink` | `#080a0b` | 表面主体（≥75% 构图） |
| `--ark-ink-2/3` | `#0d1012` / `#13171a` | 输入框 / 激活态表面 |
| `--ark-paper` | `#f4f6f6` | 正文字 |
| `--ark-signal` | `#18d1ff` | **唯一**信号色：选中、路线、进度、主操作 |
| `--ark-state` | `#c8eb21` | 仅成功/下载类次要信号（JSON 导出值） |
| `--ark-muted` / `--ark-faint` | `#8d9396` / `#4d5457` | 微标签 / 占位 |
| `--ark-panel` | `rgba(8,10,11,.82)` | 面板（半透明黑，非玻璃白卡） |

规则：中性表面占绝对多数；青色只承载"当前状态"；深度来自遮罩、裁切、半透明黑、1px 规则线与叠字，不使用光泽卡片与投影渐变。

## 2. 字体栈

| 角色 | 栈 | 用法 |
| --- | --- | --- |
| CJK UI | Noto Sans SC / Source Han Sans SC / PingFang SC | 正文 13–14px，正常字距 |
| 技术拉丁 | Space Grotesk / IBM Plex Sans | 展示数字与大编号 |
| 数据 | IBM Plex Mono | 坐标、时间戳、微标签 |

- 展示紧排：`line-height .82–.9`，`letter-spacing -.045em`（`.ark-display`、`.ark-panel__bignum`）
- 微标签开排：`letter-spacing .16em`，大写拉丁（`.ark-kicker`）
- 大小两极混排（54px 编号 ↔ 10px 索引），限制中间尺寸填充文本

## 3. 构图：舞台 + 仪表

```
┌ 顶栏 64px ── 桂 · 桂电快递导航 + GUET EXPRESS NAV · 模式芯片 · 时钟 ┐
│ 侧轨 64px                    地图舞台（全幅，暗色底图）              │
│ 索引/定位/拾取/编辑            ├ 缩放组（右上）                     │
│ 友链（竖排，底部）            ├ 实时坐标仪 LNG/LAT/Z（左下，光标跟随）│
│                              ├ 拾取提示芯片 + 十字导轨（拾取态）     │
│                              └ 路线档案（底部居中，ROUTE 态）       │
├ 索引/详情/编辑器 面板 408px（左，覆盖于舞台之上，半透明黑）           ┤
└ 状态条 30px ── 模式·信号点 · 光标/视野坐标 · ROUTE ACTIVE · 校区·GCJ-02 ┘
```

- 舞台层系统（maximal 允许 4–6 层）：① 暗色底图 ② 64px 工程网格 ③ 边缘 vignette 遮罩 ④ 十字导轨（拾取态）⑤ Marker/路线覆盖层 ⑥ 仪表组——每层都有信息角色，无纯装饰层
- 不对称平衡：左侧面板体重 + 右侧地图负空间，以规则线延伸补偿

## 4. 组件变体（全部方角 0px / 45° 斜切 / 1px 规则线）

| 组件 | Ark 语法 |
| --- | --- |
| 按钮 `.ark-btn` | 方形 + `clip-path` 右上斜切；主操作信号描边；每屏唯一实心信号按钮 |
| 模式芯片 `.ark-chip` | `[aria-pressed]` 驱动：信号字色 + 信号边 + 洗色背景 |
| 输入 `.ark-input` | 左侧 2px 刻线，聚焦转为信号色 |
| 面板标题 | 巨号编号（54px，`.82` 行高）+ 双语 meta + 延伸规则线 + 刻度尺 |
| 索引行 | 网格 `48px 1fr 20px`；激活 = 左 3px 信号条 + 洗色；meta 双行 |
| 图库 | 编辑式：大图舞台（右上斜切 + 角标括号 + 压暗遮罩）+ 边缘胶片条（激活项青色下划线）——**不是**圆角卡片堆 |
| 地图 Marker | 26px 方盒 + 等宽序号；激活 = 信号描边 + 方形角标 + 方形脉冲环（非光晕） |
| 选点标记 | 菱形（方形旋转 45°）+ 实时坐标标签 |
| 路线档案 | 底部居中仪表：左下斜切容器 + 三格等宽指标（DIST/ETA/POINTS） |
| 状态条 | 底边 30px：模式 + 呼吸信号点 + 实时经纬度 + ROUTE ACTIVE |

## 5. 状态驱动仪表化（Depth 4 核心验收项）

模式切换改变构图，而非仅换色：

| 模式 | 新增/变化的仪表 |
| --- | --- |
| 浏览 | 索引面板、坐标仪、Marker 序号态 |
| 拾取 | 十字导轨显示、顶部提示芯片、状态条箭头指向目标、坐标仪随光标实时刷新 |
| 编辑 | 编辑面板、拾取按钮信号态、草稿坐标注记 |
| 路线 | 路线档案入场（掩码上滑）、状态条 ROUTE ACTIVE、Marker 脉冲 |

## 6. 动效系统

| 家族 | 时长 | 用途 |
| --- | --- | --- |
| 直接反馈 | 180–200ms | 按钮/芯片/行悬停与按下 |
| 分节揭示 | 620ms | 面板/路线档案掩码上滑（`ark-reveal-y`）、侧滑（`ark-reveal-x`） |
| 注意循环 | 1.9s | 信号点呼吸、Marker 方形脉冲（仅激活项） |
| 路线绘制 | 1.3s | 沿路径逐帧扩展（rAF 立方缓出），完成后自动视野适配 |

`prefers-reduced-motion: reduce` 下所有动画/过渡降至 0.01ms，保留完整信息与静态构成（构建产物 CSS 已验证包含该规则；官方 `audit-ark-ui.mjs` 以单文件运行时对此有已知误报）。

## 7. 响应式重艺术指导（非等比缩放）

| 断点 | 重排 |
| --- | --- |
| ≤1180px | 面板 408 → 360px |
| ≤880px（竖屏） | 侧轨 → 底部操作条（索引/定位/拾取/编辑/友链，激活态改底部信号条）；索引 → 底部抽屉（52vh）；详情/编辑器 → 全屏覆盖层；状态条隐藏（坐标仪保留）；拾取中自动收起面板让位地图；安全区 `env(safe-area-inset-bottom)` |
| 短横屏 ≤460px | 面板上限 86vh |
